# preprints

One directory per released version: `preprints/<Title-Month-Day-Year>/`, as in `openai/math`. Each holds `README.md` (title, date and citation), the PDF, and `build/` with the TeX source and the scripts that mechanically check the manuscript. Contents are copied as snapshots of the released version; the history of the private working repositories is not imported.
